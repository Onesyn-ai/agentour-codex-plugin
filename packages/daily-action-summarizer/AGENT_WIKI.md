# 会议纪要整理助手

## Agent 目标
将会议原文整理为可核验的中文纪要和行动项。

## 开发对话流程概要
用户授权持续发布并允许 Compiler 自主选择首个实用性次要的办公 Agent。Compiler 默认选择会议纪要整理，交互策略采用持续追问；用户确认继续。其余细节为低风险默认值。

## AI 输入与输出
开发 AI 使用用户目标、平台 Contract 和模板规范，产出规范、Package、Smoke 和发布证据。Runtime 输入为会议原文或要点；输出为 Markdown 纪要。

## 工作流与业务规则
一次规划提取主题、参与者、决策、行动项、风险和待确认项；不补造事实，缺失字段标记待确认。

## 涉及资料与知识来源
无外部资料；仅使用每次运行的用户输入。

## 接口、工具与外部系统
无业务工具、MCP 或外部写入系统；仅使用平台模型运行时。

## 审批、安全与权限边界
无副作用，因此无审批工具；不声明 Secrets，不发送或写入数据。

## 验证与验收依据
本地 Validator、build-test、平台 Validation/Build/Source/Eval/Release 和真实浏览器验收。

## 已知限制
不验证会议事实的外部真实性；原文缺失的信息保持待确认。
